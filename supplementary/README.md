# Supplementary Material

Full appendix content for the paper "Speaker Identity or Communicative
Style? Pitch, Prediction, and Speaker Confounds in U.S. Presidential
Debates, 1988–2020" — the main paper's own appendix summarizes each
section and points here.

- **[`supplementary.pdf`](supplementary.pdf)** — read this. The debate
  inventory, alignment and preprocessing detail, complete feature
  definitions, full statistical results, the discourse-annotation audit,
  supplementary multimodal models, LLM methods and reproducibility
  specification, the exploratory same-candidate analysis, and known
  corpus issues.
- `supplementary.tex` — LaTeX source, self-contained with the `.cls`/`.bst`
  and two figures it references. Build with `pdflatex` + `bibtex` (twice
  more) against `sn-bibliography.bib`.

The code and derived data these results come from are in the rest of this
repository; see the top-level [`README.md`](../README.md).
