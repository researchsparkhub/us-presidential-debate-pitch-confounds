# Paper Supplement: Online Resources 1–4

Electronic Supplementary Material (ESM) for *Pitch, Prediction, and Speaker
Confounds in U.S. Presidential Debates, 1988–2020*, cited in the manuscript
text as "Online Resource 1" through "Online Resource 4" (Springer Nature's
standard in-text citation form for supplementary items), and listed with
their captions in the manuscript's Statements and Declarations section.

Each item duplicates, in a second form, a result already given as a table
or figure in the main text — provided here rather than in the main text so
the same result is not shown twice within the target journal's page-length
constraints.

| File | Caption | Duplicates in main text |
|---|---|---|
| `online_resource_1.pdf` | Within-debate standardized effect (random-effects mean, 95% CI) for the ten higher-order and dynamic pitch-contour measures. Filled markers survive Benjamini-Hochberg correction. | Table 6 |
| `online_resource_2.pdf` | Permutation importance of the top ten measures in the decision-forest model, under both holdout schemes. | Table 7 |
| `online_resource_3.pdf` | Debate-level accuracy of three classical models (weighted sum, linear discriminant, decision forest) under debate-only versus speaker-plus-debate holdout. | Table 9 |
| `online_resource_4.pdf` | The language model's debate-level outcome accuracy and exact-debate-identification rate, transcript-only versus descriptor-only input. | Figure 4 panel (b) |

Each `.tex` source and the one image asset it depends on (`fig_*.pdf`) are
included for reproducibility; the corresponding `.pdf` is the file as
submitted to the journal.

The manuscript itself, and the rest of its supplementary appendix material,
are prepared separately and are not part of this repository's scope (see
the repository root `README.md`).
